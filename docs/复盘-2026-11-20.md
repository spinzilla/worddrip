# 复盘与优化方向（2026-11-20，统筹 claude）

## 一句话结论

功能已经很全（精听、词库复习、查词、AI 小窗、写作练习、作文批改、双端同步），**接下来该做的不是再加大块功能，而是三件事**：先把数据保住，再让记住的词真的不忘，然后把「听 → 记 → 用」串成一条线。

## 现在有什么（盘点）

| 模块 | 已有 |
|---|---|
| 精听 | 视频/播客导入、字幕、逐句听写、听力句子收藏、周统计 |
| 词库 | 导入、浏览、点词查词（有道/剑桥/WordNet）、发音、例句（AI 给例句、自己写 + AI 看看）、笔记、随手记、场景标注 |
| 复习 | 首考 + 预习、到期复习（填空 / 改写 / 造句）、同日复检、闪卡；等级 L1→L4→已掌握 |
| 教练 | 作文批改、错误档案、写作练习（095/096） |
| AI | 常驻小窗、流式回复、任务不中断 |
| 多端 | 安卓 APK、双向同步、整库搬家、自动更新 |

## 发现的问题与建议（按优先级）

### P0：数据安全（先做）

- **问题**：手机从 0.11.0 原地更新到 0.11.3 时，设置和词库都被清空，原因未明。写作记录（095）、AI 任务只存在本机 localStorage，不同步。
- **建议**：
  1. 等用户更新到 0.11.4 后的诊断信息，定位原因（必要时连 USB 看 logcat）。
  2. 写作记录、词条笔记以外还只在本机的东西，逐个列出来，决定哪些进同步。
  3. 同步页加一个醒目的「上次同步：x 分钟前」，没加入同步时在首页提示一次。

### P1：复习算法——「已掌握」之后再也不考

- **问题**：现在是固定间隔 2 / 4 / 8 / 16 天（`review.rs`，照 Hermes 学习规则），L4 答对就「已掌握」并永久退出复习；任何一级答错都退回 L1；**新词首考不看释义直接答对，也立刻「已掌握」**。16 天后答对一次、或者第一次碰巧答对，并不代表半年后还记得；这是现在设计里最大的「隐形遗忘」。这套规则是用户原来定的，改不改要用户拍板。
- **参考**：Anki 新版默认的 FSRS 算法按每个词的难度和记忆稳定性算下次复习时间，官方说法是「达到同样记忆率所需复习次数更少」；开源基准用几千份真实复习记录比较各算法预测得准不准（见文末来源）。墨墨背单词也是按用户自己的遗忘曲线动态排复习，并给出遗忘曲线图。
- **建议（由轻到重，选一）**：
  - **轻**：「已掌握」改成「长期保温」：之后 45 / 90 / 180 天再各抽一次，答错退回 L3 而不是 L1。改动只在 `review.rs` 的晋级规则，一张卡。
  - **重**：换成 FSRS（有现成 TypeScript/Rust 实现），保留 L1–L4 作为界面上的「熟练度」显示。要迁移旧数据，两三张卡。
  - 两者都加一张「记忆曲线 / 熟练度分布」小图，让用户看到词在慢慢变牢。

### P1：把「听 → 记 → 用」串起来（规划里的「模块互通」一直没做）

- **问题**：`architecture-draft.md` 定的三条互通（听错的词进词库、词库词在批改时检查、错误档案 → 词库「易错点」）都还没做。现在三个模块各自好用，但不互相喂数据。
- **参考**：Language Reactor、Migaku 这类工具最受好评的就是「句子挖矿」：看剧/听力时一键把**整句 + 原声片段**存成卡片，词永远带着真实语境。
- **建议**：
  1. **精听一键收词带原句原声**：听写时点生词 → 进词库，同时把这句字幕和这段音频存成该词的例句（来源「听力原句」），闪卡背面能直接播原声。
  2. **写作练习第二期**（已规划）：批改里用错的建议用词，自动给该词记一次「答错」；常犯语法错误归进错误档案。
  3. **错误档案反哺复习**：错误档案里的高频错误，在复习出题时偶尔出一道「改错题」。

### P2：开口说——跟读（影子跟读）和口语版写作练习

- **问题**：现在练了听、读、写，完全没有「说」。
- **参考**：跟读（shadowing）的研究以听力提升证据最多，对发音、语速也有积极结果，但多为小样本研究（见文末来源）。
- **建议**：
  1. **跟读模式**：精听里每句「播原声 → 录自己 → 两段对比播放」。电脑上已有 whisper，可以把自己的录音转成文字，标出没读出来或读错的词。
  2. **口语小练**：写作练习的同一道题，可以选「说出来」，录音转文字后走同一套 AI 批改。复用 095/096，成本低。

### P2：每天打开就知道做什么

- **问题**：功能多了，入口分散在 6 个标签里。打开应用要自己决定今天练什么。
- **参考**：背单词类软件普遍有「今日任务 + 打卡 + 统计」，降低每天开始的门槛。
- **建议**：首页（或词库页顶部）一张「今天」卡片：到期复习 n 个 / 一段精听 / 一道写作题，做完一项打一个勾；连续天数和每周热力图。手机上加一个每天固定时间的系统通知（「有 12 个词到期」）。

### P3：词本身学得更深（偏学术英语）

- 搭配（collocation）：词条页显示常见搭配，造句题优先考搭配。
- 易混词：把形近、义近的词（affect/effect、adapt/adopt）放在一起对比出题。
- 词族：一个词带出它的名词/形容词形式（现在出题时只用来防泄题）。
- 学术词表（AWL）覆盖率：作文批改已经算 AWL，可以在词库里显示「AWL 第几组、还差几个」。

### P3：体验小问题（已在 `docs/交接.md` 小问题待办里，挑重要的）

- 约 170 处写死的字号不跟随「调字号」。
- 英文界面下 AI 任务标题还是中文。
- 三个旧测试脚本因选择器过期跑不过（不影响用户，影响以后回归）。
- 手机上「AI 给例句」弹抽屉盖住词条页，等用户试用后定。

## 建议的先后顺序

1. P0 数据安全（等诊断信息 → 定位 → 修）。
2. P1「已掌握」改长期保温（一张卡，见效快）。
3. P1 精听一键收词带原句原声。
4. P2 每日「今天」卡片 + 手机提醒。
5. P2 跟读 / 口语小练。
6. 其余按用户兴趣挑。
