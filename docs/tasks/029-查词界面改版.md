## 目标（一两句话，用户能看懂）

把词库页从「数据库字段表」重新设计成真正用来学习和查询的界面。怎么设计由你决定，做出你认为对这位学习者最好的版本。

## 这位学习者和他的需求

- EAP（学术英语）学习者，备考学术写作和小组讨论。习惯手写笔记，喜欢追问词义边界、搭配、语域和近义词分工。
- 词库约 486 条复习词（L1–L4 / 🌱 / ✅ / 🧊），外加约 80 组学术升级条目（口语表达 → 首选学术词 → 其他候选，带例句，部分例句是 AI 草稿）。028 之后，复习词有词性、英英释义、中文对照和例句。
- 常见的查询方式：想写「加剧」不知道用哪个词；看到一个词想知道意思、怎么用、自己学到哪了；想按某一期回看笔记。
- 他最大的老问题是「没核清语义和搭配就用词」，所以界面应该让准确的用法比华丽的词更显眼。
