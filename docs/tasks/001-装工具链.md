## 目标（一两句话，用户能看懂）

装好编译 Tauri 应用必需的两样工具：微软的 C++ 编译器（VS 生成工具）和 Rust。装完后在新开的终端里能查到版本号。

## 现状（2026-11-03 只读检查）

- 已有：Node v24.20.0 / npm 11.19.0（`D:\nodejs`）、Git 2.55、WebView2 156、cmake（`D:\mingw64\bin`）、Windows SDK（`D:\Windows Kits\10`）。
- 缺：MSVC 编译器（VS Installer 在，但没装任何 VS 产品）、Rust（rustc/cargo/rustup 都没有）。
- 磁盘：C 盘剩 90G，D 盘剩 73G。

## 安装计划（用户点头后执行）

1. **VS 2022 生成工具**：只勾「使用 C++ 的桌面开发」（MSVC + Windows SDK）。主体装 D 盘，但约 1–2G 共享组件微软强制放 C 盘。下载约 2–4G，走微软官方 CDN（大陆一般可直连）。
2. **Rust**：`rustup-init.exe`，工具链 `stable-x86_64-pc-windows-msvc`。
   - 安装位置放 D 盘：`RUSTUP_HOME=D:\rust\rustup`、`CARGO_HOME=D:\rust\cargo`。
   - 用国内镜像 rsproxy.cn（字节）：下载 rustup 和工具链；在 `D:\rust\cargo\config.toml` 配置 crates 镜像。
   - **会改用户级环境变量**：新增 RUSTUP_HOME、CARGO_HOME，并把 `D:\rust\cargo\bin` 加进用户 PATH。不改代理、TUN、网卡。

## 允许改动的路径

- `D:\rust\`（新建）
- VS 生成工具安装目录（D 盘，安装器自带的 C 盘共享目录）
- 用户级环境变量：RUSTUP_HOME、CARGO_HOME、PATH（只追加）
- 本卡片

## 验收标准（验收者照着复跑）

1. **新开** PowerShell，`rustc -V`、`cargo -V` 都能输出版本号，`rustup show` 里活动工具链是 `...-msvc`。
2. `cargo new D:\tmp\hello-rs` 后进去 `cargo run` 能打印 `Hello, world!`（证明 MSVC 链接器可用；测完删掉 `D:\tmp\hello-rs`）。
3. `D:\rust\cargo\config.toml` 里有 crates 镜像配置。

## 不做什么

- 不装 Android Studio / SDK / NDK（阶段 4 再说）。
- 不改代理、Clash、系统级 PATH。
