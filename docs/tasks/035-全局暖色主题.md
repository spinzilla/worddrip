## 目标（一两句话，用户能看懂）

把整个软件从冷白色调换成温暖、柔和、读久了不累眼的浅色调：米白/暖纸色底、暖灰文字（Claude 网页那种舒适感），主色点缀用森林绿（延续原速查网站的绿色）。所有页面（精听、词库、复习、闪卡、教练、设置）一起换，看起来是一个整体。

## 从哪看起

- 颜色变量集中在 `app/index.css` 的 `:root`（`--paper`、`--page`、`--shade`、`--line`、`--faint`、`--mute`、`--ink`、`--accent`），`app/tailwind.config.js` 引用它们。
- 约 16 个文件里还有写死的白色（`bg-white`、`#fff`、`#FFFFFF`），用 `grep -rlE "bg-white|#fff\b|#FFFFFF|#ffffff" components mobile` 找；`components/vocab/vocab.css` 也有自己的颜色。
- 移动端 `app/mobile/` 也用同一套变量。
- 原速查网站的浅色配色（参考，不必照搬）：底 `#faf9f7`、卡片 `#ffffff`/`#f2f0ec`、正文 `#252422`、次要 `#73706a`、淡字 `#a8a49d`、绿色强调 `#047857`、蓝色 `#1d4ed8`、警告 `#b45309`、错误 `#dc2626`。本地副本：`D:\tmp\es-import\参考\学术升级库-速查体验版.html`（只读）。
- 现在的强调色 `--accent: #C8311A` 是红色，同时被当作强调和焦点框；换成绿色主色后，错误/答错仍要用独立的红色，不能和主色混淆。

## 必须守住

1. **只做浅色**：不加深色模式、不加主题切换。
2. **只借风格，不仿冒品牌**：可以参考 Claude 的温暖配色气质，但不要用 Anthropic/Claude 的标志、名称、字体文件或任何商标元素。
3. **可读性**：正文与背景、次要文字与背景的对比度至少达到 WCAG AA（正文 4.5:1），在结束报告里列出主要几组颜色的对比度数值；错误/警告/成功提示仍然一眼能分清。
4. 改成用颜色变量，不再新增写死的颜色；功能和布局不改（布局升级是 036 的事）。
5. 不碰真实数据库和 `D:\english`；不装软件（不新增字体包、npm 依赖）、不提交、不推送。
