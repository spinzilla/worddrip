## 目标（一两句话，用户能看懂）

点「开始首考」后，先逐个过一遍这批 7 个词：想得起来就下一个，想不起来可以看释义。看过释义的词这次答对也先进 L1，两天后再确认，不会被算成已掌握。

## 要做的

1. **预习步骤**：点「开始首考」后先进入预习，题目照旧在后台开始准备，让用户预习时不用等出题。预习一次显示一个词，只显示单词本身和进度（如 3 / 7）。
2. **两个按钮**：
   - 「下一个」：直接到下一个词，这个词算没看释义。
   - 「看释义」：在当前词下方显示词性、英文释义、中文释义、已有例句和用户笔记，然后只留「下一个」。没有释义数据时显示「暂无释义」，仍算看过。
   - 最后一个词的「下一个」改成「开始答题」。看过的词不能撤销。
3. **跳过**：预习页常驻「跳过，直接开考」，没过到的词都算没看释义。预习页也能退出，退出时什么都不写。
4. **规则提示**：预习页写明「看过释义的词，这次答对也先进 L1，两天后再确认。」
5. **写回规则**：`ReviewSubmitRequest` 增加 `previewed`（缺省 false，到期复习不传）。状态规则只新增一条：`🌱待考察` + 产出题 + `previewed = true`，无论对错都进 L1，到期是两天后。备注追加「；<日期> 首考前看过释义」，答对答错都加。
   - 没看释义的词完全照旧：答对 `✅已掌握` 并追加「首考过」，答错 L1。
   - 四选一和同日已复习的情况照旧，不改状态。`previewed` 对 L1～L4 不起作用。
6. **结果页**：首考结果表里，看过释义的词显示「看过释义」，状态显示实际结果 L1。同日复检仍只在答错时出现。
7. **防绕过**：预习页的单词不接点词查词，预习页也不显示任何题目内容。
