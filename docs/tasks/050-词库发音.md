## 目标（一两句话，用户能看懂）

词库里的词和例句都能点一下听发音：单词优先放词典真人录音，没有就用朗读；例句用朗读。

## 从哪看起

- `app/utils/wordVoice.ts`：`createVoices(dict, tts)` 已经实现「词典录音优先、同时请求朗读、等不到就用朗读、都失败一分钟内不再请求」，`voiceFor` 是它的实例，但只通过 `forVideo` 按视频语言用。词库是英语，加一个按语言（`en`）直接取声音的出口即可，不另写一套。
- `app/utils/dictVoice.ts`：英语词典录音顺序（Cambridge，再有道），沿用。2026-11-11 实测有道 `dictvoice` 能读单词，读句子返回 500，所以句子不要走词典。
- `app/utils/speech.ts`：`loadClip(text, lang)` 用 Edge 朗读（`VOICES.en`），`playClip` / `stopClip` 保证同时只放一段。例句用这个。
- 要加播放按钮的地方：
  - `app/components/vocab/Flashcards.tsx` 背面：词（约 129 行）、词库例句（约 150 行）、我的例句（`ExamplesSection`）；
  - `app/components/vocab/EntryDetail.tsx`：词条标题、释义下的例句、我的例句；
  - `ExamplesSection.tsx` 也用在 `RecallReview.tsx` 约 1021 行（判分后的结果页），见下面防泄题。
- 发音相关的现有测试：`app/test-wordvoice.mjs`、`app/test-wordaudio.mjs`。

## 要做的

1. **单词**：词旁边一个小喇叭按钮，点了放这个词的声音：词典录音优先，没有就用朗读（复用 `createVoices` 那套，带缓存和断网保护）。
2. **例句**：每个例句旁边一个小喇叭，点了用朗读放整句。同一句这次运行里只合成一次（缓存）。
3. 同时只放一段：点新的会停掉正在放的。
4. 拿不到声音时（断网、朗读失败）：按钮短暂显示「没有声音」之类的中文提示，不弹窗、不报错、不影响翻面和其他操作。
5. 点喇叭不能触发闪卡翻面，也不能抢走快捷键（参考 `data-flash-notes` 的做法）。
6. **防泄题**：复习、首考**作答中**不出现任何播放按钮（听到发音等于给了答案）。判分后的结果页可以有，也可以不加，自定，结束报告写明。
7. 只用浅色主题、现有颜色变量；按钮小、不抢眼；1280 和 390 宽不横向溢出。
