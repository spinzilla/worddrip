## 目标（一两句话，用户能看懂）

复习和首考答题时，每道题旁边都有「记一笔」按钮，想到什么随手记下；判分后能看到这个词的全部笔记。闪卡反面也显示笔记。

## 从哪看起

- 040 的笔记存储和接口（看 `docs/tasks/040-词条笔记-存储与词库页.md` 的结束报告）。
- `app/components/vocab/RecallReview.tsx`（复习：作答 → 提交判分 → 结果页；038 的改写/造句题也在这里）、`FirstTestPanel.tsx`（首考）、`Flashcards.tsx`（闪卡）。
- 防泄题的现有做法：034 的 `utils/clickWords.ts` 遮罩、`Lookable` 在作答时禁点目标词。

## 必须守住

1. **作答中（提交前）**：每题旁边有「记一笔」按钮，点开是空白输入框。**不显示这个词的旧笔记、笔记数量，也不出现目标词或它的变形**（标题用「第 N 题」之类）。写完点保存立即入库（来源记 `复习` 或 `首考`），不受「中途退出这一屏不保存」影响，也不影响这道题的作答状态和判分。按钮不能挡住答案框和「忘记了」按钮，键盘 Tab 顺序合理。
2. **判分后**：按钮变成「笔记（n）」，展开可以看全部历史笔记（新的在上），也能继续加。
3. **首考**同样处理（作答中只能新写不能看，出结果后能看）。
4. **闪卡**：反面显示这个词的笔记（没有就不占位），并能加一条（来源 `闪卡`）。正面不显示。顺带让反面不再下半部分大片空白（笔记区可以填进去，或者内容垂直居中，由你判断）。
5. 笔记不发给出题、判分模型；改写/造句题同样适用。
6. 只用浅色主题、现有颜色变量；1280 和 390 宽都能用、不横向溢出。
7. 不碰真实数据库和 `D:\english`；不调用真实模型；不装软件、不提交、不推送。

## 结束报告（实现者填）

（claude-opus，2026-11-10）

**结论**：做完了。复习和首考的每道题旁边都有「记一笔」按钮：作答时只能新写，看不到旧笔记，也看不到有几条；判分后按钮变成「笔记（n）」，展开能看全部笔记，也能接着加。闪卡反面右栏显示这个词的笔记，也能加一条。笔记不会发给出题、判分模型。

### 改了什么
- `app/components/vocab/RecallReview.tsx`（复习和首考共用这个组件）：进来时读一次全部笔记；每题答案区底部加一行工具：左边是原来的「这题出错了」，右边是「记一笔」/「笔记（n）」按钮。点按钮会在这行下面展开笔记面板，焦点自动进输入框。面板收起时只是隐藏，不会卸载，所以没保存的草稿不会丢；从作答切到判分时草稿也还在。来源按场景写：首考记 `首考`，复习记 `复习`。
- `app/components/vocab/NotesSection.tsx`（040 写的笔记组件）：新增 `blind` 和 `label` 两个参数。`blind` 开着时不显示旧笔记列表、不显示「还没有笔记」，根元素上也不带 `data-word`；输入框的提示语和读屏标签用「第 N 题」，不用这个词本身。保存成功后显示「已保存」（不带条数）。另外，每次加、改、删成功后会广播一声「笔记变了」。
- `app/utils/vocab/notes.ts`：加了 `notifyNotesChanged` / `onNotesChanged`（用 window 事件实现，node 环境下什么都不做）。
- `app/components/vocab/BrowsePanel.tsx`：收到「笔记变了」就重新读笔记。**这是 e2e 抓到的问题**：词库页一直挂在页面上，只在切回本标签时才重读，所以复习时记的笔记，回到词库详情要手动刷新才看得到。
- `app/components/vocab/Flashcards.tsx`：反面右栏在「状态/完整备注」下面加「我的笔记（n）」（来源 `闪卡`）。没有笔记时只占一个「+ 记笔记」小按钮；正面不显示笔记。反面里要放输入框，不能再整张是一个 `<button>`，所以正面仍是按钮，反面改成 `div`：点空白处照样翻回正面，点笔记区、按钮或输入框不翻。焦点在笔记区时，闪卡快捷键（空格/方向键/Esc）暂停，让给笔记区用。
- `app/components/vocab/vocab.css`：加了 `.vocab-q-tools`、`.vocab-q-note-btn`、`.vocab-q-notes`、`.vocab-flash-side`、`.vocab-flash-notes`，只用现有颜色变量。闪卡反面从顶对齐改成垂直居中（`align-items: center`）。
- `app/test-vocab-notes.mjs`（040 的测试）：原来的静态检查规定 RecallReview、Flashcards「不准读笔记」，本卡就是要它们读，所以把这两个文件移出那张清单。改成另外检查三件事：它们调用判分、复检、写回函数时参数里没有笔记；作答中传给面板的笔记是空数组、`blind={writing}`、按钮文字是「记一笔」；闪卡不调用任何模型模块。出题、判分的工具文件仍然全部禁止读笔记。
- 新建 `app/dev/fixtures/vocab/notes-review/e2e.mjs`；`docs/ledger.md` 加了一行。

### 防泄题怎么做的
1. 作答阶段（`phase === 'write'`）组件根本不取这个词的笔记：`wordNotes = []`，传给面板的也是 `[]` 加 `blind`。所以 DOM 里既没有旧笔记正文，也没有条数，按钮只写「记一笔」。
2. 面板标题、输入框提示语、读屏标签都用「第 N 题」，不出现目标词。
3. 提交这一屏之后才用这个词的全部笔记，`label` 也换回词本身。
4. 笔记只在界面上显示，不放进题目对象，也不传给 `evaluateAnswer`、`makeRecheck`、`submitRequest`。单测和 e2e 都核对过模型请求体。
- 原来就有、不是本卡加的：题卡上的 `data-word` 属性是词条 ID（如 `exacerbate@10.20`），看不见，本卡没动它。

### 按钮放在哪
在答案区最下面一行：左边「这题出错了」，右边「记一笔」（窄屏换行时也靠右）；笔记面板在这一行下面。按钮不在答案框和「忘记了」那一行，e2e 量过三者的位置，互不重叠。Tab 顺序：答案框 → 忘记了 → 这题出错了 → 记一笔 → 笔记输入框 → 添加笔记（e2e 断言过）。回车跳下一题的老行为没变。

### 闪卡反面怎么排版
宽屏还是左边释义、右边一栏。右栏上面是灰底的「状态/到期日/完整备注」，下面是白底带边框的「我的笔记（n）」（列表、加笔记）；窄屏上下排。整块内容在卡片里垂直居中，不再上面挤、下面一大片空白（e2e 量过 1280 宽：内容上下各留 41px）。
