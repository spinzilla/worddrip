## 目标（一两句话，用户能看懂）

现在只有视频精听页、句子复习页、观看页的字幕能点词查词。把它推广到软件里所有显示英文内容的地方，例如词库里的英文释义、例句、笔记，复习题和首考题的题面，教练页的作文、批改意见和错误档案，收件箱里的候选词条。点一个英文词，就弹出和字幕里一样的查词卡。

## 从哪看起

- 现有实现：`app/hooks/useLookup.ts`（先查词典，查不到再问 AI，记住点击位置让卡片贴着词弹出），`app/components/DefinitionPanel.tsx`（查词卡），用法参考 `app/components/Studio.tsx`、`app/components/ReviewSession.tsx`、`app/components/BlurLine.tsx`。
- 要覆盖的界面大致在 `app/components/vocab/`、`app/components/coach/`。

## 必须守住

1. **复习、首考答题时不能泄露答案**：题面里点词查词可以用，但查词卡、AI 解释、发给 AI 的语境都不能出现目标词或它的变形（例如语境要用挖空后的句子，不能用填好答案的原句）。提交之后可以照常查。
2. **只处理英文**：中文、输入框、按钮文字不受影响；输入框里打字、选中复制文字等原有操作不能被破坏。
3. 只用浅色主题；390 CSS 像素宽度下查词卡能完整显示，不横向溢出。
4. 原有字幕查词的行为不变：精听页、句子复习、观看页照常能查，相关旧测试仍通过。
5. 不碰真实数据库和 `D:\english`；不调用真实模型和联网词典做验收（隔离窗口里联网请求本来就不可用，测试用假数据或本机假服务）；不装软件、不提交、不推送。
