## 目标（一两句话，用户能看懂）

在应用里任何地方点词查词，查词卡上都有「加入词库」，一点就收进词库；已经在词库里的词显示「已在词库」。只有复习、首考正在作答时不显示（防止看答案）。

## 要做成什么样

1. **先列清单**：在结束报告里列出所有点词查词的入口（桌面和手机），每个写「原来有没有按钮 → 现在有没有」。
2. **每个入口都给按钮**：
   - 来源写这个入口所在的页面（精听、看剧、阅读、闪卡……），和 042 的写法一致。
   - 闪卡、词条详情页里查的词，来源写「词库」。
3. **已在词库的词**：按钮变成「已在词库」，点了打开那个词条（用现有的 `openVocabEntry` 事件）。如果判断「在不在词库」要多查一次库，查询要快，查词卡不能因为它变慢。
4. **作答中仍然不显示**：复习、首考在作答（还没判分）时不出现按钮，这条保持 042 原样。
5. **只收英文**：日语等非英文查词，照 `manualAdd.ts` 的规则不显示按钮。
6. 手机 390 宽、`html` 字号 130% 下，查词卡底部按钮不挤、不溢出。只用浅色主题。
