## 目标（一两句话，用户能看懂）

我们自己编译的 English Studio 不再检查、提示或安装原版 LinguaClip 的更新；窗口标题和左上角名字改成「English Studio」。

## 从哪看起

- 更新开关：`app/pro/index.ts` 第 19 行 `export const UPDATES = true;`。`app/utils/update.ts` 的 `checkUpdate()` 只在 `UPDATES` 为 true 时才去检查，`app/components/UpdateUI.tsx` 的 `UpdatePill` / `UpdateDialog` 显示按钮和对话框。
- 后端：`app/src-tauri/tauri.conf.json` 约 58–61 行 `plugins.updater`（公钥 + `https://linguaclipapp.com/download/latest.json`），`app/src-tauri/src/lib.rs` 约 43 行注册 `tauri_plugin_updater`，`app/src-tauri/capabilities/default.json` 约 57 行 `"updater:default"`。
- 名字：`tauri.conf.json` 第 15 行窗口 `"title": "LinguaClip"`，`app/index.html` 第 6 行 `<title>`，`app/components/Shell.tsx` 第 32 行左上角文字。
- 设置页里如果有「检查更新」一行（搜 `updatesOn`），同样要不显示。

## 要做的

1. 前端：让更新永不检查、永不显示（推荐直接把 `UPDATES` 改成 `false`；若还有别处绕过这个开关去调 `checkForUpdate`，一并堵上）。设置页不出现检查更新的入口。
2. 后端：确保程序不会向 `linguaclipapp.com` 请求更新。可以去掉 updater 插件注册、配置和权限（连同 `Cargo.toml` 依赖），也可以只保留插件但清空地址；选哪种在结束报告里说明理由。去掉插件时 `cargo check` 必须通过，前端 `utils/desktop.ts` 里对 `@tauri-apps/plugin-updater` 的引用如果因此报错，**先回报，不要越界改**。
3. 改名：窗口标题、`index.html` 的 `<title>`、左上角文字都改成 `English Studio`。**不改** `productName`、`identifier`（会换数据目录，用户的词库就找不到了）。
4. 在 `app/dev/fixtures/brand/` 下写一个真实窗口检查脚本（照 `docs/e2e.md` 的用法，参考 `app/dev/fixtures/vocab/review-session/e2e.mjs`）：启动应用 → 等页面就绪 → 读 `document.title` 和顶栏文字 → 截一张顶栏截图 → 断言没有更新按钮。

## 验收标准（验收者照着复跑）

1. 在 `app` 目录跑 `npm.cmd run build`，退出码 0。
2. 先清掉 `CFLAGS`，在 `app/src-tauri` 跑 `cargo check`，退出码 0。
3. 在 `app` 目录跑 PowerShell `Select-String -Path pro\*.ts,utils\*.ts -Pattern 'UPDATES\s*=\s*true'`，没有输出。
4. 跑第 4 条的真实窗口脚本，退出码 0，输出里有：`document.title` 是 `English Studio`；顶栏文字含 `English Studio`、不含 `LinguaClip`；页面上找不到 `Update` 按钮。把截图路径写进验收记录，并打开截图亲眼确认左上角。
5. 打开设置页截一张图，确认没有「检查更新」之类的入口（脚本里做或手动看都行，写明是哪种）。
6. 用 `git diff --stat` 确认只改了允许的路径，并核对 `tauri.conf.json` 里 `productName`、`identifier` 没变。

## 不做什么

- 不改 `productName`、`identifier`、数据目录、Rust 包名（`linguaclip`）。
- 不删、不改任何许可证和版权声明（LinguaClip 是 AGPL-3.0）；设置 / 关于页里提到 LinguaClip 的出处说明保留。
- 不改其他界面文字里的 LinguaClip（i18n 里还有很多，另开卡）；不改默认页面（现在打开是播客页）和默认练习语言（现在是日语），这两项也另开卡。
- 不编译正式版、不动 `D:\EnglishStudio\`；正式版由统筹验收后重新编译替换。
