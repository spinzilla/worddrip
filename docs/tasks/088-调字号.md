## 目标（一两句话，用户能看懂）

在设置里能调整整个应用的字号（小 / 标准 / 大 / 特大），电脑和手机都生效，下次打开还是这个字号。

## 从哪看起

- 设置页「通用」：`app/components/` 里搜 `settingsGeneral`（i18n 键在 `app/utils/i18n.zh.ts` / `i18n.en.ts`）。
- 手机设置页：`app/mobile/` 里对应的设置组件。
- 应用启动入口 `app/index.tsx`（渲染前就要把字号设好，免得闪一下）。
- 设置快照清单：`app/utils/settingsBackupLogic.ts` 的 `SETTINGS_KEYS`。

## 要做成什么样

1. 设置 →「通用」加一项「字号」，四个选项：小（90%）、标准（100%，默认）、大（115%）、特大（130%）。用分段按钮或下拉，和这一页其他设置的样子一致。
2. 选了立刻生效：设到 `document.documentElement.style.fontSize`。
3. 存进 localStorage，下次启动在第一次渲染前就套上。
4. 这个键加进 `SETTINGS_KEYS`，并补一行单测（083 的 `test-settings-backup.mjs`）。
5. 手机设置页也有这一项，效果相同。
6. 文案中英都要（i18n）。
