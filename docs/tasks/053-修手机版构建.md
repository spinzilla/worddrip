## 目标（一两句话，用户能看懂）

让手机网页版能在这台 Windows 电脑上编译出来，并真的打开看一眼：名字是「词滴 WordDrip」，浅色主题正常，390 宽不乱。

## 从哪看起

- 2026-11-11 统筹实跑 `npm run build:mobile`（在 `app` 下），失败信息：`手机版不能用 Tauri：@tauri-apps/api/core（被 C:/workspace/english-studio/app/utils/desktop.ts 引用）`。
- `app/vite.mobile.config.ts`：`SWAP` 表用 `path.resolve` 生成键（Windows 下是反斜杠），`resolveId` 里拿 Vite 解析出的 `r.id`（正斜杠）去查表，对不上，`utils/desktop.ts` 没被换成 `mobile/platform/desktop.ts`。统筹推断这是第一个原因，修好后可能还有别的模块引用 Tauri，要一个个处理。
- `app/mobile/`：手机版入口和页面；`app/mobile/platform/`：替换桌面能力的实现。

## 允许改动的路径

- `app/vite.mobile.config.ts`
- `app/mobile/**`
- `app/utils/**`（只为了让手机版不引用 Tauri，且桌面版行为不变）

## 允许写的仓库外路径

## 要做的

1. 修好路径比对（用 Vite 的 `normalizePath` 或同等写法），让替换表在 Windows 和其他系统上都生效。
