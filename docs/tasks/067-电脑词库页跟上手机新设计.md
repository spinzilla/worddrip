## 目标（一两句话，用户能看懂）

电脑上的词库页和手机长得像一家人：打开就是今日到期和新词首考，下面一条分段切换条换视图，「添加词条」「随手记」在右上角；切视图时上面不消失、不跳。电脑独有的听力单词卡、导入、导出照样都在。

## 要做成什么样（只改电脑分支；手机分支不动）

1. **页头**：左边「词库」标题，去掉那段长说明；右边两个按钮：「＋ 添加词条」（深色主按钮，打开原来的表单）和「随手记」（描边按钮，打开 Ctrl+M 那个快捷框，按钮上用小字标 `Ctrl+M`）。
2. **复习区始终在上**：今日到期、新词首考两张卡在宽屏（≥1024px）并排两列，窄窗口上下排；不论切到哪个视图都显示，不再藏在「浏览」里。
3. **听力单词卡**（电脑独有）：原来页头的「听力单词复习 · N」「听力单词卡管理」收成复习区下面一行小入口（例如「听力单词卡：复习 N 张 · 管理」），点了和原来一样。
4. **分段切换条**：「浏览 / 场景 / 收件箱 / 随手记 / 导入 / 导出」，样式和手机、设置页一致（浅底 + 选中段白底浅阴影），随手记段带未整理数；切换时内容区短淡入、切换条不跳（可以复用手机的 `switchView` 思路，但电脑没有触摸问题，做法可以更简单）。
5. 「单词复习」入口不再单独放在页头：今日到期卡里已经有「开始复习（记进度）」和「闪卡过一遍（不记进度）」。键盘快捷键（如果原来有跳到复习的快捷键）保持能用。
6. 宽屏 1280 和窄窗口 900 都要好看；系统字号 130%（`html` 字号 130%）不溢出。
