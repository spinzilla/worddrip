## 目标（一两句话，用户能看懂）

应用里自带一份「考试词 + 核心词」数据：每个词带音标、中文意思、英文释义、词频，以及它属于四级、六级、考研、雅思、托福、GRE、高考、中考、核心 2800 词、学术词中的哪些。后面「每日新词」和「词汇量测试」都从这里取词。

## 从哪看起

- 现有本地词典的存放和读取：`app/utils/localDict*.ts`、`app/src-tauri/src/dicts.rs`。
- Tauri 资源打包：`app/src-tauri/tauri.conf.json` 的 `bundle.resources`。安卓也要能读到，参照 Tauri 2 安卓读取 resources 的写法。
- 已有的 `docs/vocab-data-model.md`。

## 要做成什么样

1. **生成脚本** `node app/dev/wordpack/build.mjs`：
   - 原始数据下载到 `D:\tmp\es-downloads\wordpack\`，不进仓库。下载地址和 sha256 写进脚本注释。GitHub 下不动可以用镜像，下载后核对 sha256。
   - 从 ECDICT 只取「至少有一个考试标签」或「在 NGSL / NAWL 里」的词。
   - 每个词保留这些字段：
     - `word`、`phonetic`、`pos`；
     - `zh`：中文释义，最多 3 行；
     - `en`：英文释义，最多 3 行；
     - `frq`、`bnc`；
     - `tags`：ECDICT 原有标签，再加上 `ngsl`、`nawl`；
     - `exchange`：词形变化，用来把 running 认成 run。
   - NGSL / NAWL 按词条原形和 ECDICT 对上，对不上的词条列进报告。
   - 输出一个数据文件，比如 `app/src-tauri/resources/wordpack/wordpack.sqlite`（或压缩 JSON，自己选，在报告里说明理由），**目标 ≤ 10 MB**，旁边放 `LICENSE-DATA.md`：
     - ECDICT 的 MIT 声明原文；
     - NGSL / NAWL 的 CC BY-SA 4.0 说明和引用写法；
     - 说明这份数据文件按 CC BY-SA 4.0 发布。
   - 脚本打印统计：总词数、每个标签多少词、文件大小。统计写进报告。
2. **读取接口**：Rust 命令加上前端封装，电脑和安卓都能用：
   - `wordpack_info()`：版本、词数、各标签词数。
   - `wordpack_list(tags, options)`：按标签取词，按词频从常见到少见排序，能排除一批已有的词，能分页。
   - `wordpack_lookup(word)`：查一个词，变形词能找到原形。
   - `wordpack_band(rank_from, rank_to, n)`：从某个词频段里随机取 n 个词，给词汇量测试用。随机数可以传种子，方便测试。
3. **打包**：电脑安装包和安卓 APK 都带上这个文件。报告写清 APK 和安装包各变大多少。
4. **致谢**：
   - README「许可证与致谢」里加 ECDICT、NGSL、NAWL；
   - 设置 → 关于 里加一行「词表数据：ECDICT（MIT）、NGSL/NAWL（CC BY-SA 4.0）」，点开能看到 `LICENSE-DATA.md` 的内容。

**3.（一般，环境）`app/dev/e2e/proc.mjs` 解不了 PowerShell 5.1 的 GBK 输出，系统里有命令行带中文的进程时所有窗口测试直接失败**
- 复现：本机 Claude 桌面端在跑（进程表里有命令行含中文的进程）时，`node dev/e2e/smoke.mjs` 在启动阶段退出 1，报 `Bad control character in string literal in JSON at position 126711/134864`；`launch.mjs stop` 同样报错，进程杀不掉。上一轮同样的脚本是通过的，说明是环境触发。
- 原因：`proc.mjs:11` 用 `encoding: 'utf8'` 读 PowerShell 输出，而 PowerShell 5.1 默认用 GBK 写 stdout，解码后混进控制字符，`JSON.parse` 失败。
- 影响：任何 agent 在这台机器上跑真实窗口测试都可能莫名失败（本轮就卡了两次）。
- 建议：在 `ps()` 的 `-Command` 前加 `[Console]::OutputEncoding = New-Object System.Text.UTF8Encoding $false;`。这个是老问题，建议记入小问题待办，不阻塞本卡。本轮验收我临时加了这一行、跑完已逐字节还原。
