## 目标（一两句话，用户能看懂）

## 要做成什么样（统筹定的方向，细节你来设计）

1. **词头区**：词头大号衬线字；下面一行放词性/音标（有就显示）、状态标签（待考察、未查证、L1… 用不同的柔和底色区分）、发音和复制按钮。词头区整体放在一个带极淡强调色底（`--accent-soft` 或 `--clay-soft` 很淡的一层）的圆角块里，和下面的内容分开。
2. **每节有自己的标识**：节标题前加一个小图标（意思、用法与辨析、例句、笔记、学习进度各一个），标题用强调色或深色加粗，节与节之间的距离统一；卡片样式分出主次（「意思」最重要：中文意思大字、英文释义衬线字；其他节用更轻的边框）。
3. **用法与辨析**：「想说 X 时可选：」后面的候选词做成一排小胶囊，当前这个词的胶囊高亮；「首选」用小标记而不是括号文字；「看整组对照 →」做成文字按钮。
4. **例句**：每句左边一条强调色竖线、衬线字，右侧发音按钮；AI 来源的小标记保留。
5. **空状态**：一行短话 + 图标 + 按钮，比如「还没有例句」下面直接是「AI 给例句」「自己写一句」两个按钮；长说明去掉或收进一个小「？」提示里。手机上不能出现「这台电脑」，改成「只存在本机」。
6. **学习进度**：L1–L5 做成一条小进度条或五个点，到期日、逾期天数用颜色区分（逾期用已有的警示色）。
7. 手机 390 宽和电脑宽屏都要好看；系统字号 130% 时不溢出、不截字。
