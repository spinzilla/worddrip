## 目标（一两句话，用户能看懂）

每个词都能看到英英释义：没有导入过的，自动从英英词典查好存进词库（标明来自哪本词典）；也可以像写笔记、写例句一样，自己写一条或几条英英释义，自己写的优先显示，还能让 AI 帮忙看写得对不对。

- 显示位置：`app/components/vocab/EntryDetail.tsx`「意思」一节、`app/components/vocab/Flashcards.tsx` 背面、手机词条页（`app/mobile/` 里对应组件）。
- 模仿对象：`app/components/vocab/NotesSection.tsx`、`app/components/vocab/ExamplesSection.tsx`、`app/utils/vocab/notes.ts`、`app/utils/vocab/examples.ts`、Rust 侧 `app/src-tauri/src/vocab/notes.rs`、`examples.rs`。

## 要做成什么样

1. **存储**：新建一张表，比如 `vocab_definition_en`，字段至少有：`id`、`word_key`、`word`、`pos`、`text`、`source`、`created_at`、`updated_at`。
   - `source` 的取值：`mine`（自己写的）、`dict:cambridge`、`dict:wiktionary`、`dict:local-wiktionary` 等。
   - 一个词可以有多条。
   - 词库版本升到 13，旧库自动升级，不动已有数据。
   - 这张表要加进同步、整库搬家（.wdlib）和 Markdown 导出。导出后再导入不丢自己写的释义。
2. **显示优先级**：「意思」一节里，英英释义按下面顺序显示：
   1. 自己写的（标「我写的」）；
   2. 导入的 `review_definition.english`（现有的，不改）；
   3. 词典查来的（小字标「来自 剑桥英英」或「来自 Wiktionary」）。
   - 一个词同时有自己写的和词典的，默认只显示自己写的。词典的收起成「词典释义（n 条）」，点开能看。
   - 闪卡背面同样按这个优先级，有就不再显示「还没有英英释义」。
3. **词典默认**：
   - **打开时自动查**：打开一个没有任何英英释义的词（详情页或闪卡背面），自动查一次英英词典：
     - 装了本地英英词典就先用本地的，否则按用户在查词设置里选的英英来源在线查。
     - 取前 1–3 个义项（带词性）存进表里，`source` 记清来源。下次不用再联网。
     - 查不到或断网时，界面安静地显示「还没有英英释义」+「自己写一条」，不弹错误。
   - **一键补全**：设置或词库页加一个「一键补全英英释义」，给所有还没有英英释义的词批量查：
     - 后台跑，显示进度，可以取消；
     - 在线查要限速，例如每秒不超过 2 个；
     - 跑完报告「补了 x 个，查不到 y 个」。
     - 参照录入笔记后台任务（073 `utils/vocab/noteJob.ts`）的做法，切页面不中断。
   - **用词典的作为起点**：词典查来的那条旁边有「改成我的」，点了把这条文字复制成一条可编辑的「我写的」。
4. **自己写**：交互和笔记、我的例句一致：
   - 「＋ 写英英释义」→ 输入框（可选词性）→ 保存。
   - 每条可编辑、可删除，删除要确认。
   - 有「AI 帮我看看」按钮：用设置里已配好的模型，检查释义是否准确、是否像英英词典的写法，给出改写建议，用户确认后才替换（照 043 改句的做法）。没配模型时不显示这个按钮。
5. **手机和电脑都要做**：手机 390 宽、`html` 字号 130% 不溢出。只用浅色主题。
6. 导入的期笔记以后如果带了英英释义，还是照旧进 `review_definition`，这张卡不改导入逻辑。

## 验收标准（验收者照着复跑）

1. 不坏老功能：
   - `cd app && npx --no-install tsc --noEmit`、`npm run build` 退出码 0；
   - `cd app/src-tauri && cargo test vocab` 退出码 0（先清掉 `CFLAGS`）；
   - `node test-platform.mjs`、`node dev/e2e/smoke.mjs` 退出码 0。
2. 升级：拿一个 v12 的测试库（fixture）启动，自动升到 13，原有词、释义、笔记、例句数量不变。
3. 单测：
   - 显示优先级（我写的 > 导入的 > 词典的）；
   - 词典结果只取前 1–3 个义项，并记录来源；
   - 查不到或断网时不写空记录；
   - 一键补全会跳过已有英英释义的词，可以取消，取消后已写入的保留。
4. 同步：用两个隔离库走一遍同步，一边写的「我写的」释义和词典释义能同步到另一边，删除也能同步过去。整库搬家导出再导入后条数一致。Markdown 导出再导入，自己写的释义不丢。
5. 真实窗口截图（电脑一张，手机 390 宽 100% 和 130% 各一张），词典请求用测试替身，不打真实网站：
   - 没有英英释义的词：打开后自动出现词典释义，并标明来源；
   - 自己写一条后，它排第一，词典释义收起；
   - 「改成我的」能把词典的那条变成可编辑的一条；
   - AI 帮我看看：用假模型返回建议，确认后替换，取消不变；
   - 闪卡背面显示同样的释义。
6. 一键补全：用 20 个词的测试库和假词典跑一次，进度条走完，报告数字正确；中途取消能停。
7. 搜一遍改动：没有写死的 API key；在线查词的限速代码在。

## 不做什么

- 不改导入期笔记的逻辑和 `review_definition` 表结构。
- 不批量自动跑一键补全（要用户点了才跑）；打开单个词时的自动查只查这一个词。
- 不做中文释义的自动查（这张卡只管英英）。
- 不上传、不连真实服务器。
