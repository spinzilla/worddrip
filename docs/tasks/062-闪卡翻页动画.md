## 目标（一两句话，用户能看懂）

闪卡翻面和换卡都有顺滑的动画：翻面是正面淡出、背面淡入（不转），换卡时卡片跟着手指滑走、下一张滑进来；在卡片正面点哪儿都是翻面，不会误弹查词。手机和电脑都受益。

## 要做成什么样（统筹定的设计）

1. **翻面**（手机、电脑都做）：**不要 3D 翻转**（用户 2026-11-13：绕轴转看着晕）。改成轻柔的交叉淡入淡出：正面淡出、背面淡入，可以带很小的位移或缩放（例如向上 8px 内、缩放 0.98–1），总时长约 200–250ms、缓出曲线。不能有旋转、不能有大幅缩放或闪烁。正反面高度不同时，卡片高度过渡要自然，不能先跳一下。翻回正面同样有动画。
2. **换卡**：
   - 手机拖动：手指按住左右拖时，卡片实时跟着手指平移（只平移，不倾斜、不旋转），松手时超过阈值（沿用 061：横向 ≥60px 且 ≥1.5 倍竖向）就继续滑出屏幕，下一张从另一侧滑入；没过阈值就弹回原位。竖向滚动背面长内容时不能触发拖动。
   - 点按钮换卡（手机、电脑都做）：当前卡朝对应方向滑出、下一张滑入，约 250–300ms。
   - 键盘 ← → 换卡（电脑）和按钮效果一样。
   - 动画进行中再点/再滑，不能卡住、不能跳过两张、不能出现两张叠在一起停住。
3. **正面不弹查词**：卡片正面整块点击 = 翻面，正面加 `data-no-lookup`（手机电脑都加）。背面保持能点词查词。
4. **减少动态效果**：系统开了「减少动态效果」（`prefers-reduced-motion: reduce`）时，翻面和换卡改成短的淡入淡出或直接切换。
5. 性能：动画只用 `transform` / `opacity`，不动画 `width/height/left/top` 之类会触发重排的属性（卡片高度过渡除外，尽量用一次性测量 + transform 或短 height 过渡）。
