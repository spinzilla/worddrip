### 三、问题清单（按严重程度）

没有导致不通过的问题；以下是低风险项/缺口，均未在当前验收中造成实际故障：

1. **【低，覆盖缺口】导出面板的 CSV 提示没有自动化验证。** 复现步骤：打开应用 → 词库 → 导出 → 点“导出复习库”（会弹系统保存对话框）。e2e 里是直接 `invoke('vocab_export')`，绕过了对话框和 ExportPanel 的结果展示，因此“词条来源与查证 CSV 已保存到…”这段界面只经过 tsc/build。是否补一条 mock 对话框的测试可另开小卡。
2. **【低】详情表单不会跟随同一词条的外部刷新。** 复现步骤：打开某个词条的详情 → 手动改来源但不保存 → 点浏览页右上角刷新按钮重新读库 → 表单仍显示刚才未保存的输入，而不是数据库里的值（`EntryDetail.tsx` 的 `useEffect` 只依赖 `item.id`）。保留未保存输入也可以解释为有意设计，任务卡未要求，故不判不通过。
3. **【低，建议】CSV 为 UTF-8 无 BOM。** 复现步骤：直接用 Excel 双击打开导出的 `词条来源与查证.csv`，中文可能乱码（未在 Excel 实测）。任务只要求 CSV 内容和列，未要求 Excel 兼容，未判失败。

**和任务无关的改动**：`docs/ledger.md` 加一行进度、本卡结束报告属于协作流程记录；`app/dev/fixtures/vocab/browse/data.json` 给测试 fixture 补 `source/verificationStatus`（筛选测试需要）；`ExportPanel.tsx` 末尾补了换行。未发现这些改动造成实际问题。
