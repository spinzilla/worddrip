## 目标（一两句话，用户能看懂）

核对识别结果时，点候选上的「第 3 页」就能看那一页的原图，能放大；电脑宽屏上左边一直显示原图、右边是候选列表，点哪条候选，左边就跳到它所在的页。

## 从哪看起

- `app/components/vocab/InboxPanel.tsx`：`pages`（`NotePage[]`，有 `thumb` 缩略图；识别用的大图在 `utils/vocab/noteMedia.ts` 生成）、候选 `Candidate.pages: number[]`（约 36 行）、候选列表渲染（约 490–545 行）。注意确认入库或「重新选择」后会 `setPages([])`。
- `app/utils/vocab/noteMedia.ts`：图片/PDF 每页渲染成长边 ≤2000px 的 JPEG，以及缩略图。
- 手机判断 `app/utils/platform.ts` 的 `IS_MOBILE`；全屏弹层可参考 `ManualAddHost.tsx` 的手机 `Overlay`。

## 要做成什么样

1. **页码可点**：候选上的「来自第 3 页」改成可点的小胶囊；一个候选来自多页时每页一个胶囊（「第 1 页」「第 3 页」）。
2. **看原图**（手机，以及电脑窄窗口 <1024px）：点页码胶囊弹出全屏查看器：
   - 显示该页大图（识别时用的那张，长边 ≤2000px），先按屏幕宽度完整显示；
   - 手机双指缩放、拖动；双击放大到 2 倍 / 再双击还原；电脑滚轮或按钮放大缩小、拖动；
   - 顶部写「第 3 / 8 页」，可以左右切到上一页 / 下一页；右上角关闭；
   - 关掉后回到候选列表原来的位置（不跳回顶部）。
3. **电脑宽屏并排**（≥1024px）：识别完成后，候选区变成左右两栏：左栏是原图查看器（同样能缩放拖动、切页，滚动时固定在可视区域），右栏是候选列表；点某条候选或它的页码胶囊，左栏跳到对应页。
4. **原图留到入库为止**：从识别完成到「确认入库」或「重新选择」之前，所有页的大图都能看；确认入库后照旧清空。内存里每页只保留一张大图（不要再多存一份原始大文件）。
5. Notion 收件箱的候选没有页码，不显示胶囊，不受影响。

**问题（按严重程度排序）**

1. 【提示】宽屏左栏比可视区域高 40px，中间候选项时看不到页面最下沿和底部提示文字。复现：1280×900 → 识别完 3 页 → 右栏滚 400px → 量 `[data-testid=note-viewer-pane]`：top=144、bottom=940，而窗口高 900。原因大概是 `h-[calc(100vh-6.5rem)]` 配 `sticky top-20`，但 sticky 的上沿是相对内层滚动容器（顶部在窗口 64px 处），所以底部露不出来。建议高度改成 `calc(100vh-9rem)` 或按容器高度算；滚到候选列表末尾时能看到，但中间核对时看不到。
2. 【提示】把候选删光后，宽屏左栏和页码胶囊会一起消失（`canView` 要求 `candidates.length > 0`），此时 `pages` 还在内存里却没有任何入口看原图，和「到确认入库 / 重新选择之前都能看」的说法不完全一致。复现：1280 宽识别完 → 逐条点删除到 0 条 → 左栏消失。建议 `canView` 不依赖候选条数，或宽屏保留左栏。
3. 【提示】宽屏下点候选行里任何位置（勾选框、词目/备注输入框、删除按钮）都会让左栏跳页，编辑词目时容易被顺带换页。复现：1280 宽 → 识别完 → 点第 3 页候选的「词目」输入框 → 左栏从第 1 页跳到第 3 页。卡片要求「点某条候选…左栏跳到对应页」，所以不算错，只是可能不想要输入框也触发；手机窄屏不受影响。
4. 【提示】`node dev/e2e/smoke.mjs` 第一次跑失败：点顶栏「视频」时等 `[data-es-e2e-target]` 3 秒超时（截图 `D:\tmp\es-e2e\20261113160206-10372\out\99-failure.png`），原地重跑退出 0。本卡没碰顶栏和 smoke 脚本，像是测试脚本自己的点击时序抖动；建议记入小问题待办，后面留意是否复现。

### 警告（调度脚本记录）
- 警告（本卡·提示）：宽屏左栏比可视区域高约 40px：1280×900 滚右栏 400px 后 note-viewer-pane 是 top=144、bottom=940，底部提示文字和页面最下沿被切掉，中间核对候选时看不到。建议：高度从 calc(100vh-6.5rem) 改成按滚动容器算（例如 calc(100vh-9rem)），让左栏底部落在窗口内。
