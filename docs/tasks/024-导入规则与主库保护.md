## 目标（一两句话，用户能看懂）

Markdown 里的复习状态变了也能重新导入，但已经在软件里复习过的词，以软件为准，不会被旧文件覆盖。

## 从哪看起

- `app/src-tauri/src/vocab/import.rs` 约 327 行：现在比较 word、issue、added_at、status、level、due、note，任何一项不同都整批拒绝。
- `app/components/vocab/ImportPanel.tsx`：结果报告。
- 012 的规则会被本卡有意修改，相关旧测试按新规则更新，并在结束报告里列出改了哪些用例。

## 要做的

1. 复习库导入改规则，同 ID 时：
   - word、issue、added_at 不同：仍判冲突，整批拒绝。
   - 只有 status、level、due、note 不同，且该词在 `review_log` 没有记录：用文件内容更新，计入「更新」。
   - 只有这些字段不同，且该词在 `review_log` 有记录：保留数据库，计入「软件较新，已跳过」。
2. 新 ID 照旧追加；来源缺行不删除；导入仍是一个事务。
3. 导入预览和结果显示新增、更新、跳过、冲突四个数字。
4. 导入面板加一行固定提示：开始在软件里复习后，这里是主库，Markdown 只作备份导出。
