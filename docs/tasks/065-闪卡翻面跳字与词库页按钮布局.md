## 目标（一两句话，用户能看懂）

闪卡翻面不再有字跳一下；词库页下半部分重新排：四个视图用一条整齐的分段切换条，「添加词条」「随手记」收进右下角一个圆形「＋」按钮里，页面不再有两个「随手记」、不再到处是深色块。手机系统字号调大时也不乱。

## 从哪看起

- 词库页手机分支：`app/components/vocab/VocabPage.tsx`（063、064 改过：两个大按钮、四个标签、底部随手记输入面板、切换时钉住高度）。

## 要做成什么样（统筹定的设计）

1. **翻面不跳字**（手机、电脑都改）：
   - 改成「先淡出、再淡入」：旧的一面在原位淡出（约 100ms），完全看不见后换内容，新的一面再淡入（约 150ms）。任何时刻屏幕上只有一面。
   - 翻面过程中卡片外框大小不变（手机上卡片本来就占满剩余高度）；旧的一面淡出时不能移动、不能重新排版。
   - 换卡（滑出滑入）和减少动态效果的行为保持 062 的样子。
2. **视图切换条**（只手机）：
   - 「浏览 / 场景 / 收件箱 / 随手记」四段等宽的分段切换条（一个浅色圆角底 + 选中段白底浅阴影，和设置页顶部分页同一种样式），占满一行；标签用短名，随手记段带未整理数小角标。
   - 系统字号 130% 时也必须一行放下、不换行不截字；放不下就再缩短内边距或字号，不许出现 3+1。
   - 064 的「切换时淡入」「切换时切换条不动」保留。
3. **「＋」浮动按钮**（只手机）：
   - 去掉两个大按钮。右下角一个圆形深色「＋」按钮（直径约 56px），在底部手势条上方、内容之上，滚动时始终可点；进复习、首考、闪卡等全屏界面时不显示。
   - 点「＋」：按钮转成「×」，上方展开两个带文字的小按钮「随手记」「添加词条」（从下往上依次出现，约 150ms），背后轻微变暗；点其中一个就执行（随手记打开 063 的底部输入面板；添加词条打开原来的表单），点暗处或「×」收起。
   - 随手记有未整理时，「＋」右上角显示一个小圆点（不写数字，数字在切换条的随手记段上）。
   - 浏览列表最底下留出足够的空白，最后一条不被「＋」挡住。
4. **切视图时上面不闪**（064 验收发现）：每次切视图，`FirstTestPanel`（以及 `DuePanel`，如有同样情况）会重新读取，读取时「还没有待考察的新词」那段消失 1–2 帧，页面变短、滚动被夹约 46px。改成切视图不触发重新读取（只在真正需要刷新时读），或读取期间保留原来的内容/占位高度。
5. 页面里除了「今日到期」的主按钮「开始复习（记进度）」和「＋」，不要再有大块深色按钮抢眼；分段切换条的选中段用白底，不用深色。
