## 要做的

1. **分页**：词库页新增「随手记」分页。默认显示「待整理」，可切到「全部」。每条显示正文、时间、上下文（字幕句和时间点、或词条），可以改正文、删除（删除先确认）。
2. **建议去向**（只用本地规则，不调模型），在每条上标出来，用户可以不听：
   - 正文只有一两个英文单词 → 建议「加入词库」；
   - 正文是一整句英文，或上下文里有字幕句 → 建议「存为例句」；
   - 正文里有问号或「为什么 / 什么意思 / 区别」之类 → 建议「问 AI」；
   - 其他 → 「留作笔记」。
3. **一键去向**：
   - 加入词库：打开 042 的手动加词，预填单词，用户确认后入库；入库成功才把随手记标为已整理（去向记「词库：词」）。
   - 存为例句：选好词后存进 043 的我的例句；成功后标为已整理。
   - 留作笔记：直接标为已整理，去向记「笔记」。
   - 问 AI：把正文和上下文发给模型，回答显示在这条下面，可以再选上面三种去向之一；只问不去向就保持待整理。
   - 已整理的条目可以「撤回到待整理」。
4. **今天的提醒**：导航「词库」旁或词库页「随手记」分页名上显示待整理条数（不要和到期数混在同一个数字里）。
5. **导出**：「导出 随手记.md」，按日期分组，每条带上下文和去向。写到用户选的位置（用现有的保存对话框）。
6. **防泄题**：复习、首考作答中不出现随手记分页和内容（保持现状即可，核对一下）。
7. 只用浅色主题、现有颜色变量；1280 和 390 宽不横向溢出。
