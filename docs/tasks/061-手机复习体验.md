## 要做成什么样（统筹定的设计，第 2–5 条只对手机生效）

1. **今日到期卡的主次**（手机、电脑都改文案，电脑布局不变）：
   - 主按钮（深色实心）是产出题复习，文字写清会记进度，例如「开始复习（记进度）」；
   - 闪卡降为次按钮，例如「闪卡过一遍（不记进度）」。
   - 具体措辞你定，但用户一眼要能分出哪个会改到期日。
2. **闪卡页**（手机）：
   - 卡片占满可用高度（顶部进度条和退出按钮、底部操作栏之间）。
   - 点卡片翻面，左右滑动切换上一张/下一张（滑动要有阈值，竖向滚动背面长内容时不能误切）。
   - 「上一张 / 翻面 / 下一张」放在屏幕底部，按钮高度不低于 44px。
   - 去掉「← → 切换 · 空格翻面 · Esc 退出」，换成手机说法（如「点卡片翻面，左右滑切换」）；「闪卡只用来回忆，不会改学习等级或到期日」这句保留。
   - 背面内容长时在卡片内部滚动，底部操作栏不跟着滚走。
3. **产出题复习、首考答题**（手机）：
   - 输入框在键盘弹出时看得见，提交/下一题按钮在底部、不被键盘挡（059 已在原生侧让网页随键盘变矮，这里保证布局跟着走）。
   - 去掉 Esc、Enter 之类的键盘提示；保留回车提交的行为不影响。
   - 题面字号在 390 宽下易读，不横向溢出。
   - 首考预习页同样检查：键盘提示、按钮位置、溢出。
4. **电脑说法换成手机说法**（手机）：
   - 「先看右边的完整备注」→ 手机上说「下面」或去掉方位词；
   - 「可在『导入』里导入期笔记」→ 手机上换成不提导入的说法（例如「这个词还没有英英释义」）；
   - 「Ctrl+Enter 让 AI 看」「Ctrl+Enter 保存」→ 手机上去掉快捷键部分；
   - 按钮的 `title` / `aria-label` 里的「（Esc）」「（空格）」手机上去掉。
   - 在 `components/vocab/` 里再搜一遍同类（空格、Esc、Ctrl、Enter、右边、左边、「导入」），手机上会显示的都处理；结束报告列出处理了哪些、哪些是只在电脑出现所以没动。
5. **按钮大小**：复习相关页面上手机的主要按钮高度不低于 44px，点按区域不重叠。

### 问题清单（按严重程度）

1. **提示（本卡）**：`DuePanel` 手机上主次按钮的排布用的是 Tailwind `max-md:` 宽度断点，而不是卡片里说的 `IS_MOBILE`。复现：电脑版把窗口拖到 768px 以下（手机 UA 为假也一样），两个按钮会变成整行宽、上下两行、主按钮在上——也就是「电脑布局不变」只在 ≥768px 宽时成立。影响：不影响 1280 桌面和本卡验收，窄窗口下的画面反而更接近手机版，用户不会点错。建议：如果要求电脑任何宽度都保持一行，改成 `IS_MOBILE` 门控。
2. **提示（本卡）**：390 宽下闪卡底部说明折成两行，第二行只剩「到期日。」（`vocab-flash-foot`）。复现：手机 390 打开闪卡任意一面看最下面一行。影响：不影响功能，只是排版丑一点。建议：把这句拆成两行，或手机上只留「点卡片翻面，左右滑切换。」加一句更短的「不记进度」。
3. **提示（本卡，同类文案漏网）**：`app/components/vocab/ScenesPanel.tsx:163` 空状态仍是「词库里还没有例句。导入词库，或在「我的例句」里加几句后，这里就能按场景找。」。复现：手机词库里一个例句都没有时点「按场景找」。影响：手机没有「导入」页，用户可能去找；实际能做事的是「设置 → 整库搬家」或「我的例句」。建议：手机分支改成「先攒几句例句：在词条里点『自己写一句』，或从另一台设备整库搬家后就有了」，记入小问题待办也行。
4. **提示（范围外，既有文案）**：`RecallReview.tsx:125` 填空的 `aria-label="空格，提示 e____"`，读屏会读成「空格（键）」，实际指的是空格子。复现：手机/电脑用读屏聚焦填空处。影响：只影响读屏理解，不是本卡引入的。建议：改成「填空，首字母 e」。
5. **提示（环境）**：`smoke`/`review-session` 页面控制台各有 2 条既有的 `plugin http not found`（调试版故意不注册 http 插件，`ES_E2E_ISOLATE=1`），本卡改动前后都一样，不影响功能。
