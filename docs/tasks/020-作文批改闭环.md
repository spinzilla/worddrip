## 要做的

1. 本地算量：词数、AWL 覆盖率（按词族匹配变形）、低于 5% 的提示；卷面类型判定（A.1），用户也可以手动选 EAP Part B / Part C / 通用学术写作。
2. 第一步请求：把 A 节规则、高频错误 Top 和程序算好的数字发给模型，要求返回结构化 JSON，内容是 ①总评（七特征短板、一句话）、②逐句改错（原句 / 问题类型 / 改法 / 为什么）、②+ 三个自查问题及答案、④与档案对照（老毛病复发 / 新问题）。
3. 第二步请求：用户点「我改完了」或「跳过」后才请求 ③整段改写示范。选「跳过」时自查答案放在最后、默认折叠。
4. 教练页加「批改作文」：粘贴作文、选卷面类型、提交、等待状态、失败提示（没配模型、网络错、JSON 解析失败），超过 400 词先问要不要继续（A.6）。
