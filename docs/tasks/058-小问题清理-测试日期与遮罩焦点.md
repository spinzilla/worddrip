- **遮罩背后能 Tab**：见 `docs/tasks/050-*.md` 验收记录问题 1。复习或首考作答时，如果之前开着词条详情，详情面板还挂在后面，只是被全屏遮罩盖住；用 Tab 能把焦点移过去，按回车会播放发音（等于泄题）。复现脚本思路在 050 验收记录里（`D:\tmp\es-e2e\verify-050-leak.mjs`，没有就照着描述自己写）。做法建议：作答遮罩打开时给背景加 `inert`（或者直接不渲染背景），关掉后恢复。
- **plugin http not found**：桌面真实窗口脚本（如 `dev/e2e/smoke.mjs`）日志里每次都有两条，053 起就有。找到是哪段前端代码调用了没注册的 `http` 插件（`@tauri-apps/plugin-http` 之类），判断是该在 Rust 里注册插件、还是前端改用已有的请求方式、还是只在某个平台才该调用。能小改就改；要装新依赖或改动大就别改，把原因和建议写进结束报告。
