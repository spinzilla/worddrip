## 目标（一两句话，用户能看懂）

做一套能反复使用的「真实窗口测试工具」：一条命令在隔离的数据目录里启动真实的 Windows Tauri 开发窗口，脚本能点页面、操作系统的文件选择框（选文件 / 取消）、截图、切窄屏、重启、只读查 SQLite，最后只关掉自己启动的进程。以后 012～015 以及所有改界面的卡都用它验收，不再每张卡临时写一次。

## 从哪看起

- `.dispatch/012-old-evidence/cdp-fixture.mjs`、`cdp-real.mjs`、`cdp-restart.mjs`、`verify-db.py`：旧电脑上为 012 临时写的脚本（只有这三份留下来），连接 WebView2 调试端口、点击、截图的写法可以参考；里面的路径（`D:/english-studio/...`、端口 9223）都是旧的，不能照抄。旧的原生对话框脚本已丢失，卡片 012 的记录里写过思路：按测试进程 PID 找到自己的文件对话框窗口，用 Win32 `WM_COMMAND` 的 ID 1（打开）/ 2（取消），不要用全局按键（会受前台焦点影响）。
- `app/src-tauri/src/lib.rs` 约 42～48 行：调试版注册 `tauri_plugin_log`，默认日志目录走 Windows 系统 Known Folder（`FOLDERID_LocalAppData`），**不读进程的 `LOCALAPPDATA`**，所以改环境变量隔离不了日志。这是 012 两次验收卡住的原因。
- `app/src-tauri/src/paths.rs`：`app_data_dir()` 读进程的 `LOCALAPPDATA`，词库数据库 `vocab.db` 在它下面的 `com.englishstudio.app`；这个改环境变量就能隔离。
- `app/src-tauri/tauri.conf.json`：开发版页面 `http://localhost:3000`，`beforeDevCommand` 是 `npm run dev`（Vite）。
- WebView2 环境变量：`WEBVIEW2_USER_DATA_FOLDER`（WebView 数据目录）、`WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=<端口>`（打开调试端口，脚本用 Chrome DevTools Protocol 连接）。
- Node 26 自带 `node:sqlite`（只读打开数据库核对，不用装 Python 或新依赖）；自带 `WebSocket` 和 `fetch`。
- 本机：Rust 产物放 `D:\rust\target`（用户环境变量 `CARGO_TARGET_DIR`），跑 cargo/tauri 前清 CFLAGS；内存 8 GB，一次只开一个 tauri 构建；C 盘空间紧，隔离数据放 `D:\tmp\es-e2e\<运行编号>\`。

## 要做的

1. **隔离启动**（`app/dev/e2e/launch.mjs`）：建 `D:\tmp\es-e2e\<运行编号>\`，下设 `localappdata`、`appdata`、`webview`、`logs`、`out`（截图和记录）。以这些目录作为子进程的 `LOCALAPPDATA`、`APPDATA`、`WEBVIEW2_USER_DATA_FOLDER`，打开调试端口（默认 9337，先确认空闲），用 `npx tauri dev` 在仓库的 `app` 目录启动（不复制整个仓库）。记录自己启动的进程 PID（含子进程）到运行目录；启动前确认 3000 和调试端口没被别的程序占用，被占就报错退出，不去关别人的进程。
2. **日志目录可隔离**（`app/src-tauri/src/lib.rs`，只改调试日志那几行）：调试版读环境变量 `ES_LOG_DIR`，有值时日志写到这个目录（`TargetKind::Folder`），没有值时行为和现在完全一样。发布版不受影响。launch.mjs 把它设成运行目录的 `logs`。
3. **页面操作库**（`app/dev/e2e/cdp.mjs`）：连接、等元素出现、按选择器或按文字点击、输入、读文本、执行脚本、整页截图、切换视口大小（含 390×844 窄屏）、等待页面重新加载。所有等待都有超时并给出中文错误。
4. **原生文件对话框**（`app/dev/e2e/dialog.mjs`，内部调用 PowerShell + Add-Type 的 Win32 代码即可）：只找属于本次测试进程的「打开文件」对话框；能填入文件路径并点「打开」，或点「取消」。找不到对话框时超时报错，不能退回到全局按键。
5. **停止与重启**（`app/dev/e2e/launch.mjs` 的 stop / restart 子命令或导出函数）：只结束自己记录的 PID；重启后同一数据目录继续用（用来验证「重启后统计还在」）。
6. **数据库只读核对**（`app/dev/e2e/db.mjs`）：用 `node:sqlite` 以只读方式打开隔离目录里的数据库，提供「数表行数」「按条件查行」两个函数；不写库。
7. **冒烟脚本**（`app/dev/e2e/smoke.mjs`）：用上面的工具在**当前主线**的应用上跑一遍：隔离启动 → 截主页 → 打开一个已有的、会弹原生文件选择框的入口（如精听导入视频/字幕），先点取消、再用 `app/TEST_SUBTITLES.srt` 或 `app/src-tauri/tests/fixtures/` 里的测试文件选一次 → 截图 → 切 390×844 窄屏截图 → 重启后再截一张 → 停止。输出都放运行目录的 `out`。
8. **说明文档**（`docs/e2e.md`）：怎么跑冒烟脚本、怎么在自己的卡里写验收脚本（给一个最小例子）、隔离了哪些目录、已知限制。用中文，大白话。
