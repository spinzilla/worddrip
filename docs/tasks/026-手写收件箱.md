## 目标（一两句话，用户能看懂）

选一张手写笔记图片，软件识别出候选词单，你改完、删完、确认后才进词库。

## 从哪看起

- `app/utils/aiConfig.ts` 的 `getEndpoint()`、`getAIConfig()`，`app/utils/ai.ts` 的调用写法。
- `docs/coach-rules/skills/english-learning/SKILL.md` 的 B.1、C.5：识别结果必须先给用户确认。
- `docs/e2e.md`：不要走系统文件对话框灌数据，测试时在页面里直接传入图片。

## 要做的

1. 词库页加「手写收件箱」：选择 PNG 或 JPG，单张不超过 8 MB，调用已配置的 OpenAI 兼容视觉接口。
2. 模型返回结构化 JSON（词目、备注、是否存疑）；格式不对时给明确报错，不能白屏。
3. 候选列表可改、可删，存疑项高亮；和词库同名的词标记「已存在」，默认不勾选。
4. 确认后作为新词写入：状态 🌱待考察，来源 `手写 YYYY-MM-DD`，查证状态 `未查证`。用户点确认前不写数据库。
5. 没配模型、网络错、超时都有中文提示。API key 不进日志、报错和截图。

### 审查三问

1. **改动的函数还有谁在用？** 新入口都只服务本卡：`vocab_inbox_confirm` → `inbox::confirm_at` 只被新面板的确认按钮和 e2e 调用；`vocabApi.confirmInbox` 只被 `InboxPanel` 调用；`InboxPanel` 只被 `VocabPage` 引用；`recognizeInboxImage`/`validateInboxImage`/`parseInboxResponse`/`normalizeInboxWord` 只在新文件、单测和假模型测试里用；`lib.rs`/`mod.rs` 只是注册和挂模块。`getEndpoint`/`getAIConfig`/`readJsonBody` 是只读复用，`ai.ts`、`aiConfig.ts` 等原有调用者没改，tsc 全绿。新增类型和 API 都是加法，无签名变更。
2. **接外部程序的部分有没有真实跑过？** 本机假模型 HTTP 服务真跑了两次：模块测试走 Node `fetch`，隔离真实窗口里经开发期的 `window.__ES_E2E_HTTP_FETCH__` 走浏览器 `fetch`。**生产用的 `@tauri-apps/plugin-http` 链路没有在真实窗口里跑过**（`docs/e2e.md` 说明 `launch.mjs` 会关掉该插件）；只做了代码审阅：capabilities 的 `http:default` 允许 `https://*/*` 和本机地址，与 `ai.ts` 等既有联网功能同一套，插件也支持 `AbortSignal`，但请把它算作未验证项。
3. **同类问题别处还有没有？** 其他 AI 调用（`utils/ai.ts`、`aiConfig.ts` 等）同样用「插件 fetch + `AbortSignal.timeout`」，也会碰到下面第 1 条的插件中断错误名问题，是既有共性，不是本卡引入；反过来 `ai.ts` 会把服务商响应片段拼进错误（有回显风险），本卡明确不回显响应正文和底层异常，这点比旧代码严。

### 问题清单（按严重程度排序，均不阻塞）

1. **（低）生产链路超时不一定显示「识别超时」。** 复现：在真实 Tauri 窗口里用插件 fetch 请求一个 60 秒不返回的地址。`@tauri-apps/plugin-http` 中断时抛的是 `Error('Request cancelled')`/字符串，不是 `AbortError`/`TimeoutError`，`utils/vocab/inbox.ts:113` 的超时分支不命中，会落到「连接视觉模型失败，请检查网络…」。仍是中文提示，但没点明超时；验收标准 1 的 Node 路径（真 `TimeoutError`）看不到这个问题。
2. **（低）8 MB 上限的实际传输没测。** 复现：用一张接近 8 MB 的真图片走完整窗口流程。e2e 只传了 9 字节假 PNG；真实图片 base64 后约 11 MB，经 Tauri IPC 交给插件再上传的耗时、内存和 60 秒超时余量未知。
3. **（低）词目/备注含 `|` 或换行时前端不拦，确认才整批报错。** 复现：把某条候选备注改成 `a | b` 再点确认，整批失败并提示「词条 X 的词目和备注不能包含换行或竖线」，需要手动改掉；数据不会写脏。
4. **（很低）同一批候选里重复词要到最后一步才发现。** 复现：模型返回两条 `same`，两条都勾选，点确认才报「所选候选里有重复词目」，需要手动删一条。
5. **（很低）所有手写入库行 `line` 固定为 1。** 浏览和导出都不显示 `line`，暂时没有可观察影响，只是数据模型上和导入行不一致。
