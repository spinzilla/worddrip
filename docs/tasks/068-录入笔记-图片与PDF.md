## 目标（一两句话，用户能看懂）

手机和电脑上都能「录入笔记」：一次选多张笔记照片或一个 PDF（手机还能直接拍），用你设置里的 AI 模型逐页认出英文词和备注，合并好给你逐条确认，再写进词库。页面上会提醒用清晰的图片或 PDF，认不好时先用扫描软件扫一遍再录。

- 手机判断 `app/utils/platform.ts` 的 `IS_MOBILE`。

## 要做成什么样

1. **改名和入口**：「手写收件箱 / 收件箱」改叫「录入笔记」（分段切换条上的短名可以叫「录笔记」或「录入」，四段/六段要放得下）。Notion 收件箱保留在同一页下方，不动它的逻辑。
2. **选文件**：
   - 一次可选多张图片（PNG/JPG，另外接受 HEIC/WEBP 的话先转 JPG）和/或一个 PDF；总页数上限 20 页（超出提示分批）。
   - 手机上额外有「拍照」按钮（`<input type="file" accept="image/*" capture="environment">`），拍完加入待识别列表；可以连拍多张。
   - 待识别列表显示每页缩略图，可删掉某页、调整顺序（顺序不是必须，删页必须有）。
3. **PDF**：用 pdfjs-dist 把每页渲染成图片（长边约 2000px，JPEG 质量约 0.85），再走和图片一样的识别。加密/损坏的 PDF 给出清楚提示。
4. **图片预处理**：长边超过 2000px 的图片先缩小再发；单张原图 8MB 上限可以放宽到 20MB（缩小后再发）。
5. **识别**：
   - 逐页调用（一次一页，最多同时 2 页），显示「第 3 / 8 页识别中…」进度和取消按钮；某页失败不影响其他页，失败页可以单独重试。
   - 所有页的结果合并：同一个词（`normalizeInboxWord` 归一后相同）只留一条，备注合并，标上来自第几页；有 `uncertain` 的标「拿不准」。
   - 候选确认、修改、删除、写入词库沿用现有流程（写入前都不进库）。
   - 提示词在现有基础上补一句：笔记里可能有中文释义、例句、划线和箭头，只提取英文词目/短语和它旁边的备注。
6. **提醒和报错**：
   - 选文件区域上方一段简短提示（一两行）：「请用清晰、光线均匀、正对拍摄的图片或 PDF。手写潦草、反光、歪斜会认不准；认不好时，先用手机自带的扫描功能或扫描类 App 扫一遍再录入。」
   - 识别完如果拿不准的条目超过一半，或某页一个词都没认出，在结果上方再提醒一次「这几页可能不够清晰，建议扫描后重录」。
   - 模型返回 HTTP 400/415 或报错里提到 image/vision 时，提示「当前模型可能不支持看图，请在『设置 → AI』换一个能看图的模型」；没配模型时按钮变灰并提示去设置。
   - 不把接口返回原文或密钥带进界面和日志（沿用现有做法）。
7. **手机和电脑都能用**，手机 390 宽、系统字号 130% 不溢出；按钮 ≥44px。
