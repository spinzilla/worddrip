## 目标（一两句话，用户能看懂）

把复习（产出题复习）、新词首考的答题界面和到期复习闪卡界面重新设计：全屏时不再空荡荡，英文释义醒目，挖空句子和要填的空一眼看清。每道题加一个「忘记了」按钮：想不起来时点它，不用硬憋。

## 从哪看起

- 答题界面：`app/components/vocab/RecallReview.tsx`（复习和首考共用，首考入口在 `FirstTestPanel.tsx`）、`app/components/vocab/vocab.css`。
- 闪卡界面：`app/components/vocab/Flashcards.tsx`（翻面后的内容也要好读：英文释义、例句、中文）。
- 判分与写回：`app/utils/vocab/grading.ts`、`app/utils/vocab/evaluate.ts`；状态规则在 Rust `review.rs`（本卡不改规则）。
- 用户截图里的现状：桌面全屏时题卡只占中间一窄条，两侧大片空白；MEANING 一行字号和正文差不多；句子和空格不够突出。
- Hermes 出题规范（参考）：`docs/coach-rules/handoff-20261110/04_QUESTIONING_AND_ASSESSMENT.md`。

## 必须守住

1. **「忘记了」算答错**：和写错一样处理（本轮记错、按现有规则写回，进入同日复检的候选），不能当成跳过或不计分；不能借它绕开升级规则。提交这一屏之前可以撤销；提交之后不能改。点了以后要让用户看到正确答案（什么时候显示由你定，但不能泄露同屏其他题的答案）。
2. 不改复习状态规则、判分规则、出题策略和防泄题逻辑；034 的点词查词在新界面里继续可用，作答前查词仍不能泄露答案。
3. 只用浅色主题；390 CSS 像素宽度下不横向溢出，桌面全屏（1920 宽左右）和普通窗口（1280 宽）都要好看、好读。
4. 键盘操作不能变差：能用 Tab/回车顺着答题，Esc 退出的现有行为不变。
5. 不碰真实数据库和 `D:\english`；验收用隔离窗口和假模型；不装软件、不提交、不推送。

- 设计取舍：
  - **宽度**：答题版心从 40rem（640px）放宽到 76rem（1216px），闪卡放宽到 64rem（1024px）。1920 宽全屏时两边各留约 350px，不再只有中间一窄条。
  - **每题左右分栏（≥1024px）**：左边 7 份放题面（题号圆标 → 英文释义 → 语境句 → 中文提示），右边 5 份放作答（首字母提示 → 输入框 + 忘记了 → 判分结果 → 这题出错了），中间用虚线隔开。这样宽屏不浪费，眼睛从题面横着扫到输入框就行。1024px 以下（包括 390）改成上下排。

    - 按钮用砖红虚线边，和主按钮分开，免得误点；

    - 点「这题出错了」会清掉「忘记了」（不计分优先）。这跟原来答错后也能标出错一样，不是新开的口子。
