## 目标（一两句话，用户能看懂）

手机上点「随手记」直接从底部弹出一个输入框，记完一句就收起，不再整页跳走；要整理随手记时，在下面「浏览 / 按场景找 / 手写收件箱 / 随手记」这排标签里切过去，上面的今日到期和首考一直待在原地。电脑版不变。

- 随手记列表/整理：`app/components/vocab/QuickNotesPanel.tsx`；未整理数：`useQuickNoteCount.ts`。

- 底部弹层可以参考 `ManualAddHost.tsx` 里 059 做的手机全屏 `Overlay`（安全区和键盘已由 059 在原生侧处理）。
- 手机判断只用 `app/utils/platform.ts` 的 `IS_MOBILE`。

## 要做成什么样（只对手机生效）

1. **「随手记」大按钮 = 快速记一笔**：
   - 点了从屏幕底部滑出一个输入面板（约 200ms 上滑，背景轻微变暗），输入框自动获得焦点、键盘弹出；面板在键盘上方，按钮不被挡。
   - 「保存」后面板收起（下滑），底部出一个小提示「已记下」，带「去整理」链接（点了切到下面的随手记标签）。空内容不能保存。
   - 点暗处、下滑面板或「取消」收起；已经输入了内容时先问一句「放弃这条？」。
   - 大按钮永远不显示「选中」状态，只有按下反馈；按钮上可以保留未整理数的小角标。
2. **标签行加上随手记**：「浏览 / 按场景找 / 手写收件箱 / 随手记」四个，随手记标签带未整理数。四个放不下一行时整齐换行或横向滑动，390 和 360 宽都不能挤字。
3. **切标签时上面不动**：
   - 今日到期、新词首考、两个大按钮在任何标签下都显示，位置不变；只有标签下面的内容区切换。
   - 内容区切换时短暂淡入（约 150ms），不要整页跳动；切换后页面滚动位置不突然跳回顶部（标签行在视口里就保持在原处）。
4. 电脑版的随手记标签、Ctrl+M 快捷框都不变。
