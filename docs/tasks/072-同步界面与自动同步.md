## 目标（一两句话，用户能看懂）

设置里多一栏「同步」：在一台设备点「开启同步」，另一台输入同步码就连上了，之后可以点「立即同步」，也会在打开应用、复习完、每隔几分钟自动同步；能看到上次同步时间和结果，出错时有中文说明。手机和电脑都有。

## 从哪看起

- 同步核心：`app/utils/sync/`（071 的 `syncNow`、状态接口），071 卡的结束报告。
- 设置页：`app/components/Settings.tsx`（手机分页由 `app/utils/platform.ts` 的 `settingsTabs` 决定）、AI 设置的写法 `app/components/SettingsAI.tsx`；AI 密钥存法 `app/utils/aiConfig.ts`（localStorage）——同步口令照同一种方式存在本机，不进仓库、不进日志。
- 整库搬家分页 `app/components/SettingsTransfer.tsx`（同步和整库搬家是两件事，界面上要分清）。
- 复习结束的时机：`app/components/vocab/RecallReview.tsx`（产出题复习保存）、首考结束。
- 服务端本机联调：`server/sync/README.md`。

## 要做成什么样

1. **设置里的「同步」**（手机、电脑都显示；可以和「整库搬家」放在同一个分页的上下两块，或单独一个分页，你定；手机分段条要放得下）。用户不用填服务器地址和口令（071 已内置），界面分三种状态：
   - **没开启**：两个按钮——「在这台设备开启同步」（调 `createSpace`，成功后立即做第一次同步）和「加入另一台设备的同步」（输入框粘贴同步码，`decodeSyncCode` 校验，抄错提示「同步码有误」）。说明一句：「第一次同步会把本机词库全部上传一次，之后只传改动。数据存放在作者的服务器上，只用于你的设备之间同步。」
   - **已开启**：显示「同步码」（默认打码，点「显示」才露出，旁边「复制」按钮）和一句提示「在另一台设备输入这个同步码即可加入。请自己保存一份，两台设备都卸载后无法找回。」；「立即同步」按钮；自动同步开关（默认开）；上次同步时间、结果（推了几条/拉了几条）、空间用量（`spaceInfo` 的 bytes / quota）、失败原因。
   - **危险操作**（折叠起来）：「这台设备退出同步」（只清本机凭证，服务器数据保留）和「删除服务器上的同步数据」（二次确认，调 `deleteSpace`，所有设备都会断开）。
   - 名额满（403）、空间满（507）、太频繁（429）、同步码失效（401）各有一句中文说明和下一步建议。
   - **高级**（折叠，默认收起）：服务器地址（默认内置值，可改，供测试用）。
   - 同步码、空间密钥存在本机（照 `aiConfig.ts` 的存法），不进日志。
   - 和整库搬家的区别写一行：「同步：两台设备自动合并改动；整库搬家：用一个文件整库覆盖。」
2. **自动同步时机**（开启后）：应用启动后、从后台回到前台、产出题复习保存后、首考结束后、随手记保存后、每 5 分钟一次；没网或失败时安静地记下失败原因，不弹窗打扰；连续失败 3 次后在词库页顶部给一条不显眼的提示「同步失败，点这里查看」。同一时间只跑一个同步。
3. **同步后刷新界面**：拉下来有改动时，词库页、今日到期、首考、随手记数字跟着刷新（用现有的「词库变了」通知）。
4. 状态小标识：顶部导航或设置入口旁一个很小的同步状态点（同步中 / 正常 / 失败），不抢眼。

### 问题清单（按严重程度）

1. **提示（本卡）**：分页改名后，空词库提示还指向旧名字。`app/components/vocab/BrowsePanel.tsx:252` 写「…到「设置 → 整库搬家」导入另一台设备的完整词库。」。复现：清空/新装后打开词库 → 看到这句 → 去设置里找不到「整库搬家」（现在叫「同步与搬家」）。影响：用户可能找不到入口，但进去就能看见整库搬家的块，不影响数据。建议：把文案改成「设置 → 同步与搬家」，顺手一起改。
