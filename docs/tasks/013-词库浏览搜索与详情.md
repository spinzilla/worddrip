## 目标（一两句话，用户能看懂）

在 012 的词库页里浏览和搜索已导入的升级词、复习词与写作自查，点开能看完整例句、来源和备注。沿用现有浅色界面，让导入的数据真正可以查阅。

## 从哪看起

- `docs/tasks/012-词库导入与结果报告.md` 的结束报告和实际 diff：复用它的页面、vocabApi、Rust 数据类型和隔离测试方式，不另建词库入口。
- `app/src-tauri/src/vocab/schema.rs`：三类主记录和例句表，查询过滤 deleted，重复词按 ID 区分。
- `app/components/ui.tsx`、`Dialog.tsx`、`index.css`：现有控件和浅色样式。`components/ReviewPage.tsx` 属于上游 FSRS，不改为 Hermes 词库。
- `docs/vocab-data-model.md` 第 1、2、5.4 节：Markdown 没有速查页 t/k/s 分类映射，首版不要凭空生成那些分类。

## 要做的

1. 扩展现有词库页，提供「学术升级 / 复习词 / 写作自查」切换、总条数、搜索框、空结果和加载失败提示；保留导入入口及结果。当前数据规模允许一次读取后本地筛选，不为此增加分页框架。
2. Rust 提供读取记录和有序例句的只读 command，前端仍只通过 vocabApi。首次未导入显示空库引导，不能为了浏览而新建库；新版数据库不兼容或读取失败须明确报错。
3. 搜索不区分英文大小写，去掉查询首尾空白，按子串匹配。升级词搜日常表达、升级表达、例句、出处和备注；复习词搜词目、期号、状态和完整备注；自查搜全文。空查询显示全部，清空后恢复默认顺序。
4. 详情显示所有字段：升级候选保留原表达，例句显示候选词和 AI 标记；复习词显示期号、原始状态、到期日、完整备注。不要仅凭斜杠拆候选而破坏括号内容。重复词分条展示并用期号/来源位置帮助区分。
5. 词库标签、加载/错误/无结果状态均用中文。优先现有控件和 Tailwind，必要样式仅作用于词库。文件内容以文本展示，禁止将 raw 或备注直接插入 HTML；长词、长备注能换行。
6. 页面离开后忽略迟到的查询响应，避免旧查询覆盖新页面。加载失败允许重试；查询与切换不更新 imported_at、updated_at、status、level 或 due。
