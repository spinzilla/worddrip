## 目标（一两句话，用户能看懂）

以后无论是更新出问题还是重装，词库和设置都能找回来：更新前自动同步一次，设置自动留一份备份，换机导出也能带上设置。每次启动还会留一条记录，下次再出事能查清原因。

## 要做成什么样

1. **更新前先同步**（电脑和手机都做）：
   - 已加入同步空间时，点「安装」前先推送一次本机改动，等推送结束再安装。
   - 推送失败（断网、服务器错）就提示「同步没成功，现在安装万一出问题，最近的改动可能找不回来。仍要安装吗？」，两个按钮是「仍要安装」和「先不装」。
   - 没加入同步时提示一句：「建议先在 设置 → 同步 里开同步，或导出整库再更新。」可以继续安装。
2. **设置自动备份**：
   - 把 localStorage 里属于本应用的设置拍一份快照，写进应用自己的数据目录。设置包括 AI 配置（含 API key）、词典来源、Anki、学习计划缓存、同步空间凭据等，具体列一张清单写进代码注释。
   - 什么时候拍：启动时、设置改动后（防抖几秒）、安装更新前，各拍一次。
   - 启动时如果 localStorage 里几乎没有本应用的键（看起来像全新），但数据目录里有快照，就弹窗问「发现之前的设置（时间），恢复吗？」。点恢复就写回并刷新页面。
   - 快照只在本机，不上传、不进同步。
3. **整库搬家带上设置**：
   - 导出 `.wdlib` 时加两个勾选：「同时导出设置」默认勾上；「包含 API key」默认不勾，勾上时提示「文件里会有你的密钥，别发给别人」。
   - 导入时，如果文件里有设置，问一句要不要恢复。
   - 旧版导出的文件（没有设置）照常能导入。
4. **启动记录**：
   - 每次启动在数据目录写一行，最多保留最近 100 行。记的是：时间、版本号、localStorage 里本应用的键数、词库词数、库文件大小、有没有设置快照。
   - 安卓上再记包的首次安装时间和最近更新时间：在 `UpdaterBridge` 加一个只读方法，读 `packageManager.getPackageInfo` 的 `firstInstallTime` 和 `lastUpdateTime`。
   - 设置 → 关于里加「复制诊断信息」按钮，复制最近 20 行加当前版本。不得包含 API key 或同步密钥。
5. **新装时提示可以从同步找回**：首次引导第一步上方加一行「以前用过词滴？输入同步加入码，把词库找回来」，点了进同步设置的「加入已有空间」。

### 审查三问

1. **改动的函数还有谁在用**：`exportWholeLibrary` / `importWholeLibrary` 只有 `components/SettingsTransfer.tsx` 调用，新参数都带默认值，旧调用方式不炸；Rust 侧 `export_at` 保留并被原有测试调用，`vocab_library_export` 只多了可选的 `settings`，`app/dev/e2e/sync.mjs` 里无参调用照样成立。`startUpdate` 仍被「继续安装」「安装失败重试」用，未改；`startUpdateGuarded` 只用在新加的「现在更新」「下载失败重试」。`syncBeforeInstall` 复用原有 `runSync`，没改同步状态机。`LibrarySummary` 只加了一个可选字段，前端只在预览里读它。
2. **接外部程序的部分有没有真实跑过**：同步服务器（本机 uvicorn + 记录请求的转发）、更新清单与安装包下载 + Tauri 签验签（本机静态服务器 + dryRun）、系统保存/打开对话框（library-transfer）、CDP 驱动的真实窗口都真跑了；安卓 `PackageManager` 那段没设备，只有编译通过；`navigator.clipboard.writeText` 只验了文本内容（不含密钥），没读回剪贴板确认真的写进去了。
3. **同类问题别处还有没有**：更新前的保护覆盖了提示条上的「现在更新 / 下载失败重试」，没覆盖「继续安装 / 安装失败重试」（那里已经下载过，不重复同步，属有意）；恢复判断用的是本应用键数 ≤2 的粗略阈值，正常用过的一眼能区分，但只配了两项设置的用户不会被问（快照也得超过两项才问，边界已写进单测）；同类的「设置没被快照到」问题我只找到 `linguaclip_loop`（见问题 4）。

### 问题清单（按严重程度）

1. 【提示｜本卡】同步失败、确认框弹出时，提示条上还挂着「正在同步本机改动，同步完再安装…」，和弹窗里的「同步没成功」同时出现，看着自相矛盾。复现：加入同步 → 把同步地址改成 `127.0.0.1:1` → 点「现在更新」→ 看顶部提示条（截图 `update-083-1794707354425\out\sync-failed-confirm.png`）。建议：弹确认框前先把 `preparing` 置回 false，或把这行改成中性的「正在检查同步…」。
2. 【提示｜本卡】提示条里的「建议先在 设置 → 同步 里开同步，或导出整库再更新」直接读 localStorage，没有订阅同步状态；开着提示条去设置里开同步，回到首页这行要等下一次重渲染才消失。复现：没开同步时让提示条出现 → 设置里开启同步 → 回首页看提示条。建议：用 `subscribeSync` 订阅，和「现在更新」按钮的可用状态一起放进快照。
3. 【提示｜本卡】新加的两处文案没进 i18n：恢复弹窗（`SettingsRestorePrompt.tsx`）和引导第一步行「以前用过词滴？输入同步加入码…」是写死的中文；同一批的更新提示、复制诊断信息都做了中英。英文界面下这两处仍显示中文。建议：补 `diag.*` / `restore.*` 一类键；如果决定只给中文，在卡片或注释里写明。
4. 【提示｜本卡】设置清单漏了 `linguaclip_loop`（句循环开关和次数，算用户偏好不是缓存），恢复或整库搬家后这个偏好会回到默认；`linguaclip_listen_level` 也没在清单注释里说明为什么不算。复现：开句循环 → 清 localStorage 后恢复 → 循环设置没回来。建议：把要恢复的键加进 `SETTINGS_KEYS` 并补一行单测，不想带的就写进「不进快照」的注释。
5. 【提示｜本卡】`app/dev/e2e/update-083.mjs` 断言的是「有 /pull 或 /push」就算过了，可空库时其实只有 pull，卡片要求的「先推送」没被脚本自己证明（我这次是另加一个词手工补的）。建议：脚本里先加一个词再点「现在更新」，直接断言出现 `POST /push` 且排在下载之前。
6. 【提示｜本卡】`app/dev/e2e/update-077-mobile.mjs` 把「更新内容」按钮和说明面板的断言改成了「有才点」，发布清单没写更新说明时这块 UI 不再检查，覆盖变小了一点。建议：测试清单固定带一句 notes，或者单独保留一次有说明的断言。
7. 【提示｜环境】安卓 `installTimes()`（读首次安装/最近更新时间）和系统安装流程只在编译层面过了，没在真机/模拟器上跑；本机没有设备，卡片允许只做代码审阅，这条留着下次上机补。
