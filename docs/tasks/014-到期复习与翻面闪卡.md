## 目标（一两句话，用户能看懂）

在词库页看到今天到期和已经逾期的词，并能进入翻面闪卡复习。翻卡只帮助查看和回忆，不自动改学习等级或到期日期。

## 从哪看起

- `docs/tasks/013-词库浏览搜索与详情.md` 及其实际产物：复用 vocabApi、查询结果和详情样式，不另造数据源。
- `app/utils/vocab/types.ts`：复习词的 status、level、due 与 ID；同词多行不能按词文本合并。
- `docs/vocab-data-model.md` 第 1.2、3 节：L1–L4 是参与到期筛选的集合，不代表所有活跃词今天都到期；闪卡不负责晋级。
- `app/components/ReviewSession.tsx` 属于现有 FSRS 学习流程，只参考交互，不复用其写回评分行为。

## 要做的

1. 词库页增加到期数量、到期列表和「开始复习」。只收未软删除、状态与 level 对应 L1–L4、日期合法且 due 不晚于本机今天的记录；待考察、已掌握、冷库、空日期、无效日期均不进入。
2. 日期按本机自然日比较，不用 UTC 的 `toISOString().slice(0, 10)` 推断今天，不把 YYYY-MM-DD 当 UTC 时刻。测试能传入固定今天；生产在进入页和窗口重新获得焦点时刷新日期。
3. 默认按到期日升序、再按原顺序及 ID 稳定排序；同词不同 ID 分别显示。无到期词给出明确空态并禁用开始，不出现空闪卡或 NaN 进度。
4. 闪卡正面显示词目和期号，翻面显示完整备注、状态和到期日；支持点击/按钮翻面、上一张、下一张、进度和退出。每次切卡回到正面；首尾禁用越界按钮，最后一张提供结束，不写入「已掌握」。
5. Esc 退出；方向键切换、空格翻面仅在闪卡活动且焦点不在输入控件时处理。退出/切页清理事件，不能残留监听影响听写快捷键。页面正常按钮能获得键盘焦点。
6. 本次进入闪卡固定一份队列；不靠异步更新在用户正看的卡上跳项。退出后重新进入再刷新。复习前后数据库所有业务字段及 import_run 不变。

## 不做什么

- 不增加写数据库接口，不做 L 级晋升、答题判分、AI 出题、FSRS 换算、每日替换推荐或同步。

- 不派发其他 agent、不改 agent-board、不提交推送。按 012 → 013 → 014 → 015 串行，完成界面验收后由统筹单卡复核。
