## 要做的

1. **数据不搬家**：听力单词继续存在 IndexedDB，保留自己的复习规则和听写形式；不迁移进 SQLite，不进词库的 Markdown 导出。词库数据也不动。
2. **词库页合并显示**：词库页的列表里同时显示词库的词和听力单词。听力来的词带「听力」小标记。能筛选「全部 / 听力 / 非听力」，每项显示数量。
3. **同一个词两边都有**（按归一化后的词比较）：显示成一条，带「听力」标记；详情里两边的信息都能看到；两边的复习进度各算各的，互不影响。
4. **听力单词的详情**：显示释义、听力里的原句，能播放原声片段（复用 `clips.ts`），能点单词发音。只在听力里有的词，详情里不出现词库专属的操作（或者给出明确的中文说明为什么不能用）。
5. **两个复习入口**：词库页上「单词复习」（现有词库规则）和「听力单词复习」（原「单词」页的复习流程，规则不变），各自显示到期数。
6. **导航**：去掉「单词」；「词库」上显示到期数（词库到期 + 听力单词到期之和）。「句子」改名成更明确的听力句子入口（如「听力句子」，英文界面同步改），里面不动。
7. 原「单词」页上还有用的功能（比如 Anki 导出、单词卡列表的管理操作）要有地方能找到，结束报告列出每个功能挪到了哪。
8. **防泄题**：两种复习作答中都不出现原声、发音按钮和释义（保持现状）。
9. 只用浅色主题、现有颜色变量；1280 和 390 宽不横向溢出（窄屏导航本来就是横向滚动，保持）。
